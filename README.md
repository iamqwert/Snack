# 贪吃蛇 / Snake

纯前端、单文件即可运行的贪吃蛇，支持本地双人对战与人机对战。

## 功能
- 单人 / 双人 / 人机（积分赛、生存赛）
- 生命、原地复活、初始生命 1–5
- 道具：穿墙无敌、减速、磁铁吸附、星星加速、红心加命
- 难度：简单 / 默认 / 困难（静止怪 + 移动怪）
- 音效、音量、开始菜单 BGM、失败音乐
- 主题：浅色 / 深色 / 跟随系统
- 语言：简体中文 / 繁體中文 / English / 跟随系统

## 运行
用浏览器打开 `index.html` 即可，无需构建。

## 操作
- 方向键 / WASD 移动（人机可选键位）
- Space / Esc 开始或暂停

## 技术
HTML + CSS + 原生 JavaScript + Canvas + Web Audio

# Snake

A pure frontend, single-file snake game that supports local two-player battles and human-vs-machine matches.

## Features
- Single / Two-player / Human-vs-machine (score race, survival mode)
- Lives, on-the-spot respawn, 1–5 initial lives
- Items: wall-pass invincibility, slow-down, magnet attraction, star speed boost, heart for extra life
- Difficulty: Easy / Normal / Hard (static enemies + moving enemies)
- Sound effects, volume, start menu BGM, game over music
- Themes: Light / Dark / Follow system
- Languages: Simplified Chinese / Traditional Chinese / English / Follow system

## Run
Simply open `index.html` in a browser—no build required.

## Controls
- Arrow keys / WASD to move (selectable for human-vs-machine)
- Space / Esc to start or pause

## Tech
HTML + CSS + Vanilla JavaScript + Canvas + Web Audio
